# 05 · GDScript 语法基础

> 占位章节，待撰写。

本章计划内容：

- 文件结构：`extends` 必须在首行、`class_name` 全局注册
- 变量 / 常量 / 类型推断（`var x := 10`、`const PI := 3.14`）
- 函数：参数、默认参数、返回值、可变参数
- 控制流：if / elif / else、match、while、for、break / continue
- 数据结构：Array、Dictionary、内置常用方法
- 字符串：格式化（`%s`、`{}`）、多行 `"""`、原始字符串 `r""`
- 运算符：算术、比较、逻辑、三元化简
- 注释与文档注释 `## `
- 与 Python / TypeScript 的关键差异对照表
