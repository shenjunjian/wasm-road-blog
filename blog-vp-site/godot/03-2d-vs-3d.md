# 03 · 2D 与 3D：选型与关键区别

> 占位章节，待撰写。

本章计划内容：

- 坐标系差异：2D 用像素 (x, y) + z_index，3D 用世界单位 (x, y, z)
- 摄像机差异：Camera2D / Camera3D 各自的工作原理
- 渲染对象：CanvasItem 体系 vs Node3D 体系
- Z 排序 vs 深度缓冲：2D 靠 Z-index / y-sort，3D 靠 depth buffer
- 美术资产差异：像素图集 / sprite sheet vs 模型 + UV + 贴图
- 性能取舍：2D 几乎不挑显卡，3D 在中低端机器要降级
